# Tarefa agendada no Claude Desktop: enviar o relatório ARCAFLA pelo WhatsApp

Como usar:
1. Abra o Claude Desktop no computador, que precisa ficar ligado e acordado por volta das 11h.
2. Deixe o WhatsApp Desktop aberto e conectado.
3. Crie uma tarefa agendada (Scheduled task) para **todo dia às 11:20**.
4. Cole como instrução o texto entre as linhas abaixo, trocando **[CONTATO]** pelo nome do contato ou grupo como
   aparece no WhatsApp.
5. Na primeira execução, aprove as permissões que o Claude pedir: controle do computador, WhatsApp e acesso ao
   GitHub. Depois disso, a tarefa roda sozinha.

---

Todo dia, envie pelo WhatsApp Desktop o relatório diário do rebanho da Fazenda ARCAFLA. Escreva em português.

1. No repositório GitHub `helem130516-ux/arkafla`, branch `claude/tender-clarke-13z0dx`, pegue os arquivos mais
   recentes:
   - a imagem `monitoramento/imagens/ARCAFLA_AAAA-MM-DD_pagina-1.png`, com a data mais recente;
   - o PDF `monitoramento/Monitoramento_Diario_ARCAFLA_AAAA-MM-DD.pdf`, da mesma data.

   Baixe os dois para a pasta Downloads.
2. Se a data mais recente não for a de ontem, ainda não há relatório novo. Espere 20 minutos e tente de novo, até
   3 vezes. Se continuar sem relatório, não envie nada e avise só a mim.
3. Abra o WhatsApp Desktop, procure o contato **[CONTATO]** e envie:
   - a imagem da página 1, com a legenda "ARCAFLA – Monitoramento de DD/MM";
   - logo depois, o PDF.
4. Confira na tela se as duas mensagens foram enviadas (com o sinal de enviado).
5. Ao terminar, me diga em uma linha: a data do relatório e se o envio deu certo.

Regras:
- Envie somente para [CONTATO]. Não mande nada para nenhum outro contato.
- Não escreva nem leia outras conversas.
- Não altere nada no repositório.
- Se o WhatsApp pedir QR Code ou estiver desconectado, não tente resolver: avise e pare.

---

Observações:
- A rotina na nuvem gera o relatório às 10h48 e leva poucos minutos. As 11:20 dão folga.
- O controle do computador (computer use) só existe no **Mac** e pede plano Pro ou Max.
- Se o computador estiver desligado ou dormindo às 11:20, a tarefa não roda. O relatório continua chegando no app
  do Claude no celular.
